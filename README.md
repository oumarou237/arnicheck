# ArniCheck 🛡️

Application mobile qui aide à identifier les arnaques par SMS, email, appel 
ou lien suspect — et protège les proches grâce au Bouclier Famille.

## 🎯 Le problème

Les arnaques par message explosent, en partie à cause de l'IA générative qui 
rend les tentatives de phishing de plus en plus convaincantes. Les personnes 
les plus vulnérables (personnes âgées, jeunes) manquent d'outils simples pour 
vérifier un message avant d'agir.

## 💡 La solution

ArniCheck analyse messages, liens et appels suspects et donne un verdict clair 
(sûr / suspect / danger), avec des explications pédagogiques — sans jamais 
culpabiliser l'utilisateur. Son différenciateur : le **Bouclier Famille**, qui 
permet de protéger ses proches en centralisant les vérifications.

## ✨ Fonctionnalités

- Vérification de messages, liens et appels suspects
- Bouclier Famille pour protéger ses proches
- Fil "Alertes du moment" avec signalement communautaire
- Historique et recherche des analyses passées
- Badges et streak de vigilance
- Rapport hebdomadaire et analyse IA approfondie (Premium)
- Mode clair/sombre

## 💳 Monétisation

Modèle freemium géré via **RevenueCat** :
- Gratuit : 5 analyses/mois, 1 proche protégé
- Premium : analyses illimitées, proches illimités, rapport hebdo, analyse IA approfondie

React, Vite, Tailwind CSS, RevenueCat
